## 비교 실험 결과 (`team_project/experiments/`)

두 실험 모두 한 번에 하나만 바꾸고, 같은 데이터 분리(훈련 50,000 / 검증 10,000)에서 10에폭 학습했습니다. 시드 3개로 반복해 **검증 정확도의 평균 ± 표준편차**를 적었습니다. 시험 데이터는 쓰지 않았습니다.

### ① 옵티마이저 비교 (`compare_optimizer.py`, 강의 6.1.8절)

고정: 784 → 256 → 128 → 64 → 10, He, 배치 정규화, 드롭아웃 0.2, 가중치 감소 5e-7. 학습률은 교재 예제처럼 각 옵티마이저의 기본값입니다.

| 옵티마이저 | 학습률 | 1에폭 후 val | 10에폭 후 val |
| --- | --- | --- | --- |
| SGD | 0.01 | 77.12% | 86.28% ± 0.08%p |
| Momentum | 0.01 | 84.77% | 88.85% ± 0.07%p |
| AdaGrad | 0.01 | **86.36%** | 89.07% ± 0.06%p |
| Adam | 0.001 | 85.67% | **89.20% ± 0.34%p** |

- SGD가 가장 느리고 정확도도 약 3%p 낮습니다. 나머지 셋은 처음부터 빠르게 학습합니다. 강의 6.1.8절 MNIST 결과와 같은 경향입니다.
- 1에폭 후에는 AdaGrad가 가장 빨랐습니다. 이것도 강의의 "AdaGrad가 가장 빠름"과 같습니다.
- 10에폭 후에는 Adam이 가장 높지만, AdaGrad와의 차이(0.13%p)가 Adam의 표준편차(0.34%p)보다 작아서 **사실상 비슷**합니다.
- 결론: SGD 대신 적응적 옵티마이저를 쓰는 것이 확실히 좋고, 그중 최근 가장 많이 쓰는 Adam을 최종 모델에 유지했습니다.

### 은닉층 깊이 × 너비 비교 (`compare_depth.py`, 모델 결정)

은닉층 1~4개 × 층마다 뉴런 64·128·256개, 12가지 조합을 모든 은닉층 너비를 같게 하여 비교했습니다. 시드 2개, 10에폭이고, 비교 기준은 **에폭별 검증 정확도 중 가장 좋았던 에폭의 값**(마지막 에폭 값은 출렁임이 커서 쓰지 않음)의 시드 평균입니다. 고정: Adam(lr 0.001), He, 배치 정규화, 드롭아웃 0.2, 가중치 감소 5e-7. 그래프는 `compare_depth_width.png`입니다.

| 은닉층 수 \ 너비 | 64 | 128 | 256 |
| --- | --- | --- | --- |
| 1 | 88.18% | 89.31% | 88.97% |
| 2 | 88.44% | 89.34% | 89.65% |
| **3** | 88.16% | 89.28% | **89.76%** |
| 4 | 88.25% | 88.98% | 89.44% |

- **은닉층 3개 × 너비 256이 가장 높았습니다(89.76%).** 은닉층 2개 × 256(89.65%)과는 0.11%p 차이라 사실상 비슷합니다.
- 너비가 가장 큰 영향을 줬습니다. 너비 64는 깊이와 상관없이 약 88.2~88.4%로 가장 낮았고, 너비 256은 깊이 2~4에서 가장 높았습니다.
- 깊이는 영향이 작았습니다. 너비 256에서는 은닉층 2~3개가 좋았고, 4개로 늘리면 오히려 떨어졌습니다. "깊을수록 좋다"는 이 문제·이 학습량(10에폭)에서는 성립하지 않았습니다.
- 가장 큰 너비(256)에서 최고가 나왔으므로, 256보다 큰 너비는 아직 확인하지 않았습니다.
- 이 결과로 최종 모델을 은닉층 3개 × 너비 256으로 정했습니다.
- 참고: 처음에는 너비를 100으로 고정하고 은닉층 1~5개를 시드 3개로 비교했습니다(val 88.35~89.00%, 은닉층 2개가 최고). 너비가 작으면 깊이에 따른 차이가 작았고, 너비를 키우는 효과가 더 컸습니다.

## 하이퍼파라미터 탐색 결과 (`hyperparameter_search.py`)

강의 6.5.3절 방식대로 두 번 탐색했습니다. 시간을 줄이려고 훈련 데이터 10,000장, 5에폭만 학습했습니다.

| 차수 | 범위 | 횟수 |
| --- | --- | --- |
| 1차 | 학습률 1e-6 ~ 1e-2, 가중치 감소 1e-8 ~ 1e-4 (강의와 같은 범위) | 30회 |
| 2차 | 1차 상위 5개를 포함하는 범위: 학습률 1.1e-3 ~ 7.9e-3, 가중치 감소 1.0e-7 ~ 2.5e-5 | 20회 |

- 학습률이 1e-5보다 작으면 5에폭 안에 거의 학습되지 않았습니다(val 10~50%).
- 상위 5개: val 85.3~85.7%, 학습률 1.7e-3 ~ 2.9e-3, 가중치 감소 2.7e-7 ~ 3.6e-6
- 상위권끼리는 차이가 0.4%p 이내라 사실상 비슷합니다. 그 가운데 값(학습률 0.0025, 가중치 감소 5e-7)으로 정했습니다.
- 가중치 감소 계수는 작은 쪽이 좋았습니다. 배치 정규화와 드롭아웃이 이미 오버피팅을 억제하고 있기 때문으로 보입니다(6.3.1절: 배치 정규화는 오버피팅 억제 효과가 있음).

## 실행 결과 (제 환경에서 실행, 시드 고정)

| 모델 | 설정 | 최고 val acc | test acc |
| --- | --- | --- | --- |
| 1단계 기준 모델 | 784 → 50 → 10, SGD 학습률 0.1 | 88.11% | 86.06% |
| 최종 모델 (탐색 전) | 784 → 256 → 128 → 64 → 10, Adam 학습률 0.001, 가중치 감소 1e-4 | 89.63% | 88.55% |
| 최종 모델 (하이퍼파라미터 탐색 후) | 784 → 256 → 128 → 64 → 10, Adam 학습률 0.0025, 가중치 감소 5e-7 | 89.89% | 88.61% |
| **최종 모델 (너비 탐색 후)** | 784 → 256 → 256 → 256 → 10, Adam 학습률 0.0025, 가중치 감소 5e-7 | **90.26%** | **88.83%** |

- 하이퍼파라미터 탐색으로 val acc가 0.26%p, 은닉층 너비를 256으로 통일하자 0.37%p 더 올랐습니다. 크지 않은 차이라, 시드를 바꿔 여러 번 돌려 보면 더 확실히 비교할 수 있습니다.
- (이전 모델 256 → 128 → 64 기준) 200장 시험 5회: 87.0~91.5%
- (이전 모델 256 → 128 → 64 기준) 가장 많이 틀리는 옷: Shirt 61%, Pullover 81%, Coat 82%
- 최고 val acc가 마지막 에폭(19)에서 나왔습니다. 에폭을 늘리면 조금 더 오를 가능성이 있습니다.
- 컴퓨터(NumPy 버전 등)에 따라 숫자는 조금 다를 수 있습니다.
