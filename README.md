## 13주 "팀플: 학습관련 기술들"과 최종 모델

| 항목 | 최종 모델의 선택 | 강의 |
| --- | --- | --- |
| 모델 결정 (층 수, 층별 노드 수) | 784 → 256 → 128 → 64 → 10 (은닉층 3개, Affine 4층) | 6.5절 (검증 데이터로 결정) |
| ① Optimizer | Adam (β1=0.9, β2=0.999 기본값) | 6.1절 |
| ② 초깃값 | He (ReLU를 쓰므로) | 6.2절 |
| ③ 배치 정규화 | 사용 | 6.3절 |
| ④ 오버피팅 방지 | 가중치 감소 + 드롭아웃 0.2 | 6.4절 |
| ⑤ 하이퍼파라미터 최적화 | Randomized Grid Search로 학습률 0.0025, 가중치 감소 계수 5e-7 결정 | 6.5절 |

**아직 실험으로 비교하지 않은 것**: 모델 구조(층 수·노드 수), ① SGD·Momentum·AdaGrad와의 비교, ② Xavier와의 비교, ③·④ 사용/미사용 비교. 지금은 강의의 권장 사항(예: ReLU에는 He)을 따른 상태입니다. 팀에서 하나씩 바꿔 가며 검증 정확도로 비교하면 각 선택의 근거가 됩니다.

## 하이퍼파라미터 탐색 결과 (`hyperparameter_search.py`)

강의 6.5.3절 방식대로 두 번 탐색했습니다. 시간을 줄이려고 훈련 데이터 10,000장, 5에폭만 학습했습니다.

| 차수 | 범위 | 횟수 |
| --- | --- | --- |
| 1차 | 학습률 1e-6 ~ 1e-2, 가중치 감소 1e-8 ~ 1e-4 (강의와 같은 범위) | 30회 |
| 2차 | 1차 상위 5개를 포함하는 범위: 학습률 1.1e-3 ~ 7.9e-3, 가중치 감소 1.0e-7 ~ 2.5e-5 | 20회 |

- 학습률이 1e-5보다 작으면 5에폭 안에 거의 학습되지 않았습니다(val 10~50%).
- 상위 5개: val 85.3~85.7%, 학습률 1.7e-3 ~ 2.9e-3, 가중치 감소 2.7e-7 ~ 3.6e-6
- 상위권끼리는 차이가 0.4%p 이내라 사실상 비슷합니다. 그 가운데 값(학습률 0.0025, 가중치 감소 5e-7)으로 정했습니다.
- 가중치 감소 계수는 작은 쪽이 좋았습니다. 배치 정규화와 드롭아웃이 이미 오버피팅을 억제하고 있기 때문으로 보입니다(6.3.1절: 배치 정규화는 오버피팅 억제 효과가 있음).

## 실행 결과 (제 환경에서 실행, 시드 고정)

| 모델 | 설정 | 최고 val acc | test acc |
| --- | --- | --- | --- |
| 1단계 기준 모델 | 784 → 50 → 10, SGD 학습률 0.1 | 88.11% | 86.06% |
| 최종 모델 (탐색 전) | Adam 학습률 0.001, 가중치 감소 1e-4 | 89.63% | 88.55% |
| **최종 모델 (탐색 후)** | Adam 학습률 0.0025, 가중치 감소 5e-7 | **89.89%** | **88.61%** |

- 탐색으로 val acc가 0.26%p 올랐습니다. 크지 않은 차이라, 시드를 바꿔 여러 번 돌려 보면 더 확실히 비교할 수 있습니다.
- 200장 시험 5회: 87.0~91.5%
- 가장 많이 틀리는 옷: Shirt 61%, Pullover 81%, Coat 82%
- 최고 val acc가 마지막 에폭(19)에서 나왔습니다. 에폭을 늘리면 조금 더 오를 가능성이 있습니다.
- 컴퓨터(NumPy 버전 등)에 따라 숫자는 조금 다를 수 있습니다.
